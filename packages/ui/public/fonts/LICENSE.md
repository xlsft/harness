# Bundled fonts

Terminal fonts from Nerd Fonts v3.4.0 (https://github.com/ryanoasis/nerd-fonts, `patched-fonts/`):

- CaskaydiaCove Nerd Font (Regular, Bold): Cascadia Code by Microsoft, patched with Nerd Fonts glyphs.
- JetBrainsMono Nerd Font Mono (Regular, Bold): JetBrains Mono by JetBrains, patched with Nerd Fonts glyphs.

Both are licensed under the SIL Open Font License 1.1 (https://openfontlicense.org). The Nerd Fonts patcher and
