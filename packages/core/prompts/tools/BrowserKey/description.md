Presses keys in the active tab, as on a keyboard. `keys` is a space-separated sequence of keys or combinations, for example `Enter`, `Tab`, `Escape`, `ArrowDown`, `Backspace`, `PageDown`, `F5`, `ctrl+a`, `shift+Tab` or `meta+Enter`. Modifiers are ctrl, shift, alt and meta (cmd). A single character presses that key (`a`; `A` adds shift); write `plus` for the + key. `repeat` presses the whole sequence that many times (at most 100).

- Keys go to the focused element: click or type into a field first when needed.
- Use it for keyboard navigation, shortcuts, closing popups (Escape), picking from autocomplete lists (ArrowDown, then Enter) and submitting (Enter).
- Editing shortcuts (select all, copy, cut, paste, undo, redo) work with ctrl or meta.
- When the keys start a navigation, the call waits for the new page and says so.
