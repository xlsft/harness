Stops the command that runs in a tab of the Terminal pane: an interrupt first, then stronger signals if it does not react within a few seconds. The shell and the tab stay. It does nothing when the tab is idle.

A tab you opened with TerminalRun or TerminalOpen needs no permission, as long as the user has not typed in it. Stopping anything in a tab of the user's always needs their approval, in every permission mode, so do it only when they asked or it clearly serves what they asked for.
