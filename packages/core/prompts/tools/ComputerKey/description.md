Presses keys in an app with the full tier. `keys` is one or more combinations separated by spaces, such as `cmd+s` or `tab tab enter`. Modifiers: cmd, ctrl, alt, shift. Named keys: enter, tab, space, delete, forward_delete, escape, up, down, left, right, home, end, page_up, page_down, f1 to f12.

Combinations that act outside the app are refused by default, such as system search, switching apps and logging out; use ComputerActivate to change app. While a secure field has the focus, only keys that move around it work.
