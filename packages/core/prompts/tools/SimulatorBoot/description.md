Boots an iOS Simulator device and waits until it has finished starting, which can take a minute the first time. A device that is already booted is left as it is.

The device runs headless: nothing opens on the user's screen, and the user watches it in the Simulator pane. Prefer a device that is already booted, and boot another only when the task needs a particular model or iOS version. Several booted devices use a lot of memory; tell the user which one you booted.
