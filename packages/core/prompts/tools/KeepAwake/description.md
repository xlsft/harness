Turns on or off the session's "Keep computer awake" switch, the same one the user has in the Tools menu. While it is on, the machine running the session does not go to sleep as long as this session is working; between turns it may sleep as usual. Closing the session releases it.

Use it for long unattended work when the user asks, or when they ask you not to let the machine sleep. Turn it off again once it is no longer wanted.
