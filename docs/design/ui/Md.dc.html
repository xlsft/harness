Gateway: streaming responses

The gateway takes a request in Anthropic Messages format, sends it to any OpenAI-compatible provider and streams it back with no buffering extra latency. The handler is defineHandler from Nitro, the contract lives in proto/gateway/v1. Command palette: ⌘ K.

Event order

The provider sends usage as a separate chunk after the text, so message_stop is held until it arrives.

Timeouts

Provider retries

Only 429 and 5xx are retried, with exponential backoff[1].

[1] Base delay 500 ms, factor 2, at most 5 attempts.
